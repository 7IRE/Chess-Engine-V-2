### If you wanna use this project in your project you need to change some things before you can use it .

Renderer Class - Current Default Renderer is Default Terminal GUI which uses custom ASCII characters .  

Input Class - This Class is Used to Read Raw Character and cause changes accordingly.

####  Optional Changes
SelectionFunction in Board Class - If you wanna change how Input works , This function is Responsible for Selecting The Piece by reading inputs , on implementing Cursor Selection , this function needs to be changed to directly read rank and file on different part of selection of screen.
